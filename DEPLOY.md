# Deploy Rehberi

Bu proje statik HTML, CSS ve JavaScript dosyalarından oluşur. GitHub Pages için ek build adımı gerekmez.

## GitHub Pages

1. Değişiklikleri commit edin.
2. Repoyu GitHub'a gönderin.
3. GitHub'da `Settings > Pages` ekranına gidin.
4. Source olarak `Deploy from a branch` seçin.
5. Branch olarak `main`, klasör olarak `/ (root)` seçin.

Yayın adresi:

https://myildirimer.github.io/metercontrol/
