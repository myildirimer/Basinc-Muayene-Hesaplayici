# Metercontrol

Basınç ölçer ve hacim ölçek muayeneleri için tarayıcıda çalışan statik hesaplama aracı.

## Modüller

- `basinc.html`: basınç ölçer muayenesi, nokta önerisi, MİH ve uygunluk özeti.
- `hacim.html`: hacim ölçek muayenesi, sıcaklık düzeltmesi, hata ve uygunluk özeti.
